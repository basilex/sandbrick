# Contributing to Sandbrick

Thank you for considering contributing to **Sandbrick**! We welcome all kinds of contributions — bug reports, pull requests, documentation updates, or feature ideas.

## 🚀 Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Make your changes.
5. Submit a Pull Request (PR).

Please keep your PRs small, focused, and well-documented.

## 📦 Code Style

- Follow Kotlin best practices.
- Ensure code is clean, commented, and well-tested.
- Use meaningful commit messages.

## ✅ Checklist Before PR

- [ ] All tests pass
- [ ] No linter or style errors
- [ ] Code is documented
- [ ] Changes are related to an open issue or clearly described

## 🙌 Need Help?

Open a GitHub Discussion or reach out via Issues tab. We're here to collaborate!
