# Contributing to Sandbrick

Thanks for your interest in contributing to **Sandbrick**! Whether you're fixing a bug, adding a feature, or improving documentation, your help is appreciated.

## Getting Started

1. Fork the repository.
2. Create a new branch: `git checkout -b feature/your-feature-name`
3. Make your changes.
4. Write tests if applicable.
5. Run tests and make sure everything passes.
6. Commit your changes: `git commit -m "Add feature X"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Open a pull request (PR) on the `main` branch.

## Code Style

- Kotlin code should follow standard conventions (use Kotlin formatter in your IDE).
- Keep methods small and focused.
- Use meaningful variable and function names.

## Pull Requests

- All PRs must be reviewed before merging.
- Describe your changes clearly.
- Link any related issues in the description (e.g. `Fixes #42`).

## Communication

If you have questions, ideas, or want to discuss something before opening a PR, feel free to open a [GitHub Discussion](https://github.com/YOUR_ORG/sandbrick/discussions) or reach out directly.

Happy coding! 🧱
